# Wearable HRV Biofeedback + Remote Coaching Reduces Anxiety (Chung 2021)

## Summary

An 8-week pilot using the Lief Smart Patch (consumer wearable HRV biofeedback) combined with remote stress management coaching reduced GAD-2 anxiety scores from 4.6 to 1.7 (p < .001) and increased RMSSD by +11.4 ms per biofeedback session. Demonstrates that consumer wearables + coaching can effectively reduce clinical anxiety.

## Key Claims Relevant to SRL

- Consumer wearable HRV biofeedback produces clinical-grade anxiety reduction
- RMSSD increase of +11.4 ms per session = measurable vagal tone improvement
- Remote coaching component validates the human-guided element of Pausality
- Supports [[readyscore]] concept — RMSSD as actionable outcome metric
