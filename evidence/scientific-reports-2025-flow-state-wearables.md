## Citation

(Authors, 2025). Physiological assessment of the psychological flow state using wearable devices. *Scientific Reports*. https://www.nature.com/articles/s41598-025-95647-x

## Key Findings

- Demonstrated feasibility of detecting and monitoring the **flow state** using wearable physiological sensors in real-world conditions.
- Flow correlates were identifiable from EEG, HRV, and other physiological signals captured via consumer-grade wearables.
- AI and advanced statistical methods were applied to decode cognitive/flow states from brainwave and autonomic data in real time.
- Establishes wearable-based flow detection as a viable foundation for performance monitoring in athletes, workers, and high-demand contexts.

## Relevance to SRL

Directly supports the Cognitive Variability Analysis framework — real-time state detection now appears possible via wearable sensors. For SRL's vision of a clinician performance monitoring ecosystem, this is a key enabling technology. Also reinforces Anterocept and State Transition concepts: if flow is physiologically detectable, entry into and exit from optimal states becomes a trainable, measurable event.

## Methodology

- **Design:** Observational feasibility study
- **Measures:** Wearable EEG, HRV, and other physiological signals
- **Analysis:** AI/ML classification of flow vs. non-flow states
- **Context:** Real-world task performance conditions
