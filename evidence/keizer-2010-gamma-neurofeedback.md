# Gamma Neurofeedback Enhances Cognitive Binding (Keizer et al. 2010)

## Summary

This study demonstrated that gamma-band (>30 Hz) neurofeedback training enhances cognitive feature binding — the brain's ability to integrate separate perceptual features (shape, color, location) into coherent representations. This is directly relevant to clinical performance where multiple information streams must be integrated simultaneously.

## Key Claims Relevant to SRL

- Gamma-band training improves cognitive integration (feature binding)
- Supports [[neuroharmonics]] gamma layer (40 Hz) for task-positive focus
- Validates the Tupac Ranch "Laser Focus Activator" protocol (40Hz binaural + nostril breathing)
- Mechanism: gamma oscillations synchronize distributed neural populations for coherent processing

## Concepts Derived

- [[neuroharmonics]] — gamma frequency (>30 Hz) for cognitive enhancement, not just relaxation
- [[polyanchora]] — multi-feature binding is the neural mechanism underlying multi-anchor attention
- [[cognitive-variability-analysis]] — gamma power as a marker of cognitive integration capacity
