# Neurofeedback Training Facilitates Awareness: A 7T MRI Study (Ganesan et al. 2025)

## Summary

Using ultra-high-field 7T fMRI, this study demonstrates that neurofeedback targeting the posterior cingulate cortex (PCC) — a key hub of the default mode network and self-referential processing — helps novice meditators learn to disengage from self-referential thought. Participants received real-time feedback about PCC activity and learned to down-regulate it, producing subjective reports of increased present-centered awareness. This is significant for SRL because it shows that technology can accelerate the attentional shift from narrative self-preoccupation to present-centered body awareness — the same shift that NeuroMinute targets through breath-mediated training. The 7T resolution provides unprecedented detail about the PCC dynamics involved.

## Key Claims Relevant to SRL

- PCC-targeted neurofeedback enables novices to learn disengagement from self-referential thought
- The PCC is a key hub for self-referential processing and the default mode network
- Down-regulating PCC activity produces increased present-centered awareness
- Technology can accelerate attentional shifts normally requiring extensive meditation training
- 7T fMRI provides unprecedented spatial resolution for tracking meditation-relevant brain changes
- Novice meditators can achieve measurable shifts in a single session with neurofeedback support
- The findings suggest potential for technology-assisted onboarding to meditation and breathwork
