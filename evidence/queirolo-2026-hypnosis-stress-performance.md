## Summary

Study demonstrating that a single personalized hypnosis session can reshape the multilevel stress response and enhance executive performance in stressed medical students.

## Key Findings

- **Intervention:** Single personalized hypnosis session
- **Executive function:** Improved with medium effect size (d=0.62)
- **Autonomic response:** Increased parasympathetic recovery (measured via HRV), reduced stress and anxiety
- **Autonomic profile:** Produced an "adaptive challenge-like autonomic profile" — shifting from threat to challenge state
- **Single-session efficacy:** Demonstrates that meaningful autonomic and cognitive shifts can occur in a single session

## SRL Relevance

This is the closest published analog to the NeuroMinute concept — a single, brief intervention that simultaneously shifts autonomic state AND improves executive function. The "adaptive challenge-like autonomic profile" language maps directly to Somnistics' state transition framework. The d=0.62 effect size from ONE session validates the minimum effective dose approach.
