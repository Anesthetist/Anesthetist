## Citation

(2025). Physiological assessment of the psychological flow state using wearable devices. *Scientific Reports*. https://doi.org/10.1038/s41598-025-95647-x

## Key Findings

- Demonstrates feasibility of detecting and monitoring flow states in real-time using wearable physiological devices — a significant methodological advance for flow research.
- Flow states produce measurable, distinctive physiological signatures accessible via consumer-grade wearables, opening pathways to objective flow state detection in naturalistic settings.
- Advances the possibility of real-time flow state feedback systems for performance optimization.
- Connects the subjective phenomenology of flow to objective biosignals (likely HRV, skin conductance, and/or EEG metrics).

## Relevance to SRL

Critical supporting evidence for SRL's State Transition and Cognitive Variability Analysis concepts — demonstrating that optimal performance states have quantifiable physiological markers that can be tracked via wearables. This opens the door for SRL's ExterOryx and wearable-augmented Gap Moment Training applications. Real-time flow detection could enable adaptive biofeedback protocols that guide practitioners into and through optimal performance states.

## Methodology

- Empirical study using wearable physiological measurement devices.
- Participants performed tasks designed to induce flow state.
- Physiological data correlated with validated flow state self-report measures.
- Published in *Scientific Reports*, 2025.
