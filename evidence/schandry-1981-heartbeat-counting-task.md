## Summary

Schandry (1981) created the Heartbeat Counting Task — the original behavioral interoception measure. Published in *Psychophysiology* 18(4):483-488.

## Key Findings

1. Developed the heartbeat counting/tracking task
2. Participants count heartbeats in timed intervals without touching pulse
3. Accuracy = 1 - (|actual - counted| / actual)
4. Demonstrated individual differences in cardiac perception
5. Became the most widely used interoceptive accuracy task for 40+ years

## SRL Relevance

The foundational behavioral measure. SRL should know its limitations (confounded by beliefs, time estimation) but it remains the most-cited starting point for all interoception measurement.
