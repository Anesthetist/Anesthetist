# Insula as Hub for Interoception, Time, and Self (Giotakos 2025)

## Summary

Comprehensive review establishing the insular cortex as a convergence hub linking interoceptive predictive coding, time perception accuracy, and self-representation. Key finding: interoceptive accuracy correlates with BOTH vagal activity AND time perception accuracy — connecting body awareness to temporal processing.

## Key Claims Relevant to SRL

- Insula links interoception + time perception + self-awareness (three functions in one hub)
- Validates [[breath-as-time-engineer]] — interoceptive training may improve temporal processing
- Interoceptive accuracy correlates with vagal activity — training one improves the other
- Supports [[anterocept]] as targeting the insula's predictive coding function

## Concepts Derived

- [[anterocept]] — training the insula's anticipatory/predictive function
- [[interoception]] — insula as the hub linking body awareness to time and self
- [[breath-as-time-engineer]] — neurobiological validation that interoception and temporal perception share a substrate
- [[self-remembering]] — insula mediates self-representation
