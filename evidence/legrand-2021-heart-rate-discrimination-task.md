## Overview
Legrand et al. introduce and validate the Heart Rate Discrimination (HRD) task, a psychophysical method for assessing cardiac interoceptive accuracy. Unlike the traditional heartbeat counting task, the HRD uses an adaptive staircase procedure that estimates both accuracy and precision of cardiac interoception. Validated in 223 healthy adults, the task also measures metacognitive efficiency and is available as an open-source Python implementation (Cardioception package).

## Key Findings
1. Adaptive psychophysical procedure that estimates both interoceptive accuracy (threshold) AND precision (slope) — a major advance over Schandry's heartbeat counting task
2. Also measures metacognitive efficiency — how well people know what they know about their own heartbeat
3. Validated in N=223 healthy adults with robust psychometric properties
4. Open-source Python implementation available via the Cardioception package, enabling replication and clinical adoption
5. Reframes interoceptive beliefs as functional machinery rather than confound — beliefs about heartbeat detection are themselves informative about interoceptive processing

## Connection to Somnistics
The HRD task is the behavioral measure SRL should use for clinical validation studies. It is more rigorous than Schandry's heartbeat counting task, open-source, and uniquely measures metacognition — which maps directly to [[interoceptive-literacy]]. As SRL moves toward enterprise clinical validation (Red Arrow 3), this task provides the gold-standard outcome measure for proving that breathwork-based training improves cardiac interoception.
