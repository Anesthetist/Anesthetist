# Stephan's Computational Psychiatry

**Most rigorous framework for mapping therapy to measurable computational parameters.**

Stephan's approach models mental disorders as disruptions in computational processes (learning rates, prediction precision, salience processing). Therapy is understood as modifying these computational parameters.

## Key Concept: Allostatic Self-Efficacy

Stephan (2016) proposed that interoceptive training builds **allostatic self-efficacy** — the brain's learned confidence that it can regulate its own internal states. This maps directly to SRL's [[autonomic-home-base]] concept.

## Relevance to SRL / Neurotagging

If neurotagging captures session-level biometric data (RMSSD before/after, respiratory rate, HR), computational models could be fitted to that data to extract:
- **Interoceptive precision** (how accurately the brain predicts body state)
- **Learning rate** (how fast the user's autonomic system adapts to training)
- **State transition efficiency** (how quickly they return to home base after disruption)

These are the computational parameters behind [[state-drift]], [[state-transition-intelligence]], and [[embodied-metacognition]].

## Gap

Computational psychiatry is abstract and requires sophisticated model-fitting. Neurotagging provides the raw data layer that computational models need but currently lack — structured, session-level, intervention-tagged biometric streams.
