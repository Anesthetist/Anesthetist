## Citation

(2025). Physiological assessment of the psychological flow state using wearable devices. *Nature Scientific Reports*. https://doi.org/10.1038/s41598-025-95647-x

## Key Findings

- Demonstrated feasibility of detecting and monitoring psychological flow states using wearable devices
- Flow — the state of optimal experience — can be identified through physiological signatures captured by consumer wearables
- Moves flow state research from lab-based subjective report paradigms toward real-time, objective physiological measurement
- Opens pathways for flow state optimization in real-world performance contexts

## Relevance to SRL

Directly relevant to SRL's **Neurogating** and **State Transition** concepts. If flow states can be detected via wearables, this validates the potential for real-time state monitoring during clinical performance — a core aspiration of the **Gap Moment Detection Engine**. Also supports **ExterOryx** and **Cognitive Variability Analysis** by providing objective markers of optimal performance states.

## Methodology

Wearable device-based physiological monitoring during flow-inducing tasks. Published in *Nature Scientific Reports* (2025). Compared physiological signatures during flow vs. non-flow conditions.
