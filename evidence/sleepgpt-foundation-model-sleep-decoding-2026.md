## Citation

A unified time-frequency foundation model for sleep decoding. *Nature Communications*, 2025. DOI: 10.1038/s41467-025-67970-4

## Key Findings

- Introduced SleepGPT, a generative pretrained transformer model for sleep decoding
- Sets new benchmark for sleep staging, sleep-related pathology classification, and sleep spindle detection
- Unified model handles multiple sleep decoding tasks rather than requiring task-specific models
- Leverages time-frequency representation of EEG data for superior performance

## Relevance to SRL

Relevant to SRL's technology vision — a foundation model for sleep analysis could power Pausality's sleep monitoring features. Sleep spindle detection is particularly relevant to SomnoAffinity and cognitive performance optimization, as spindles are markers of memory consolidation. Integration with SRL's Multimodal Sensor Fusion approach could enable personalized sleep architecture analysis.

## Methodology

Deep learning (generative pretrained transformer architecture); time-frequency EEG representations; benchmarked against existing sleep staging and pathology classification methods.
