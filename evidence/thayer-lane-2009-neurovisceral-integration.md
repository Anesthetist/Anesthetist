# Neurovisceral Integration Model (Thayer & Lane 2009)

## Summary

The neurovisceral integration model proposes that heart rate variability reflects the functional capacity of a central autonomic network linking the prefrontal cortex to the heart via the vagus nerve. Higher HRV = greater prefrontal regulatory capacity = better cognitive flexibility, emotional regulation, and stress tolerance. This model provides the theoretical foundation for using HRV as a proxy for cognitive readiness.

## Key Claims Relevant to SRL

- HRV indexes prefrontal cortex regulatory capacity
- Low HRV predicts poor cognitive flexibility and emotional dysregulation
- The heart-brain connection is bidirectional — breathing can influence prefrontal function via vagal afferents
- HRV is a biomarker of adaptive stress response capacity
