# Resting-State fMRI Functional Connectivity and Mindfulness (Sezer, Pizzagalli & Sacchet 2022)

## Summary

This review systematically examines resting-state functional connectivity (FC) changes produced by mindfulness meditation across clinical and non-clinical populations. Three core networks emerge as consistently altered: the default mode network (DMN, associated with self-referential processing), the salience network (detecting relevance), and the frontoparietal network (executive control). Mindfulness practice reduces DMN hyperconnectivity (associated with rumination and depression), enhances salience network function (supporting interoceptive awareness), and strengthens frontoparietal engagement (supporting top-down regulation). For SRL, this paper maps how breath-mediated mindfulness rewires the brain's resting architecture — the neural infrastructure that determines baseline cognitive-emotional functioning between active tasks.

## Key Claims Relevant to SRL

- Mindfulness alters resting-state functional connectivity in three core networks: DMN, salience, and frontoparietal
- Reduced DMN hyperconnectivity correlates with decreased rumination and self-referential processing
- Enhanced salience network function supports improved interoceptive awareness and relevance detection
- Frontoparietal network strengthening enables better top-down attentional and emotional regulation
- These FC changes appear in both clinical (depression, anxiety, PTSD) and non-clinical populations
- Changes in resting-state architecture persist beyond active meditation — they reshape the baseline brain
- The three-network model maps onto SRL's attention control, self-awareness, and emotion regulation framework
