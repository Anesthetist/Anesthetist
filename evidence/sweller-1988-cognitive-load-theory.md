# Cognitive Load During Problem Solving: Effects on Learning

## Summary

John Sweller (1988) introduced **Cognitive Load Theory (CLT)**, arguing that instructional design must account for the limited capacity of working memory. The theory distinguishes between **intrinsic load** (inherent complexity of the material), **extraneous load** (unnecessary complexity introduced by poor instruction), and **germane load** (effort devoted to schema construction and automation). When total cognitive load exceeds working memory capacity, learning fails.

## Key Contributions

- **Three types of cognitive load**: Intrinsic (determined by element interactivity of the material), extraneous (determined by instructional design quality), and germane (productive effort toward learning)
- **Working memory bottleneck**: Working memory can hold approximately 4-7 elements simultaneously; instruction that exceeds this capacity produces no learning regardless of motivation or effort
- **Element interactivity**: The more elements that must be processed simultaneously (rather than sequentially), the higher the intrinsic load — complex skills have irreducibly high element interactivity
- **Redundancy effect**: Presenting the same information in multiple formats simultaneously can increase rather than decrease cognitive load
- **Split-attention effect**: When learners must mentally integrate information from multiple sources, the integration itself consumes working memory

## Methodological Notes

- Experimental studies using problem-solving tasks (algebra, geometry)
- Theory has been extensively validated and extended over three decades (Sweller, Ayres, & Kalyuga, 2011)
- Connects to Miller's (1956) working memory limits and Baddeley's working memory model
- Over 10,000 citations; one of the most influential frameworks in instructional design

## Challenge to SRL

Layering interoceptive attention + breath pacing + binaural entrainment + haptic feedback in a 60-second NeuroMinute window may **exceed working memory capacity**, especially for novices. Each modality requires its own attentional allocation. If the total element interactivity of a multi-layer protocol exceeds working memory limits, the learner processes none of the layers effectively — they experience cognitive overload rather than integrated regulation. This is not a minor concern: CLT predicts that the very sophistication of SRL's multi-modal approach could be its undoing for the novice population that needs it most.

## SRL Response

The layered intervention stack is designed to **titrate complexity**. Novices receive single-layer protocols (breath only, or body scan only). Layers are added only after the previous layer has reached sufficient automaticity to reduce its cognitive load footprint. This mirrors Bernstein's freezing/freeing — freeze the extra layers until the user can handle them. The 60-second window contains as many layers as the user's current skill level supports, not a fixed stack. However, this response requires empirical validation: does the titration actually prevent overload, or does it merely delay it?

## Design Constraint

**If a protocol layer has not been automatized in isolation, it cannot be stacked. Total element interactivity of any NeuroMinute must not exceed the user's current working memory capacity.**

## SRL Relevance

CLT is the primary adversarial framework for SRL's multi-modal intervention design. It forces discipline: every new layer added to a protocol must be justified by evidence that previous layers have been sufficiently automatized. The concept of germane load is also relevant — SRL protocols should maximize germane load (effort toward building regulatory schemas) while minimizing extraneous load (confusing interfaces, unnecessary instructions, poorly sequenced content).
