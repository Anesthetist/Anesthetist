## Citation

Linares Gutiérrez, D., Kübel, S. L., Giersch, A., & Wittmann, M. (2019). Meditation-induced states, vagal tone, and breathing activity are related to changes in auditory temporal integration. *Behavioral Sciences*, 9(5), 51. [DOI: 10.3390/bs9050051](https://doi.org/10.3390/bs9050051)

## Key Findings

- Meditation-induced states directly modulate auditory temporal integration — the window within which separate sounds are perceived as a single event
- **Vagal tone** (measured via HRV) during meditation correlates with changes in temporal integration thresholds
- **Breathing activity** during meditation is independently associated with temporal integration changes
- Higher vagal tone during meditation → wider temporal integration window → more events perceived as unified
- This establishes a direct, measurable pathway: breathing → vagal tone → temporal processing

## The Vagal-Temporal Chain

```
Breathing pattern (slow, rhythmic)
  → Vagal afferent activation
    → Increased vagal tone (higher RMSSD)
      → Modulated insular cortex activation
        → Changed temporal integration thresholds
          → Altered perception of event boundaries
```

## Relevance to SRL

**This is the smoking gun linking SRL's breathing interventions to temporal processing:**

- **Resonant breathing** at 5.5 breaths/min maximizes vagal tone, which by this paper's findings directly modulates temporal integration — the perceptual window within which events are bound together
- **Gap moments** may work partly by changing the temporal integration window: a brief breath intervention shifts the clinician from a narrow (stress-compressed) temporal window to a broader (regulated) one, literally changing how many events are perceived as simultaneous vs. sequential
- **Vagal tone as temporal marker:** RMSSD isn't just an autonomic metric — it's a proxy for temporal processing capacity. When SRL measures HRV improvement, it's measuring temporal flexibility improvement.
- **Clinical time pressure:** Under low vagal tone (high stress), temporal integration narrows — events feel rapid, overlapping, chaotic. Under high vagal tone (regulated), temporal integration broadens — events feel sequenced, manageable. This is the subjective experience CRNAs describe as "having enough time" vs. "drowning."

## Methodology

Meditation practitioners completed auditory temporal integration tasks before and during meditation. Simultaneous ECG (for HRV/vagal tone) and respiratory monitoring. Analyzed correlations between meditation state, autonomic measures, and temporal processing thresholds.
