An AI system that selects and adjusts intervention parameters on-the-fly based on real-time physiological state classification. The protocol adapts breathing pace, modality mix (audio/haptic/visual), difficulty level, and duration based on what the user's body is doing right now.

## Decision Logic

1. Classify current state (focused, stressed, flow, dysregulated, recovering)
2. Select protocol from library based on state + context + user history
3. Set initial parameters (breathing ratio, pace, sensory modality)
4. Monitor biometric response during delivery
5. Adjust parameters mid-protocol if state delta is insufficient
6. Escalate to longer or different protocol if 60-second intervention is inadequate

## Distinction from Static Protocols

Traditional breathwork apps deliver the same protocol regardless of user state. Adaptive intervention protocols are responsive — the same user might receive different breathing ratios on different days depending on their incoming autonomic state.
