Breathing synchronized to the user's own heartbeat rather than an external clock. The key differentiator from every other breathwork app on the market. Requires real-time cardiac data from wearables (Apple Watch, Whoop, Oura, Muse).

Real-time heart rate and HRV data drive the breath pacing cues, so the user becomes aware of their internal rhythmic state and learns to synchronize breath with heartbeat. This trains heart-brain coherence and shifts the locus of control from external timing to embodied timing.

## Competitive Differentiation

Every consumer breathwork app (Calm, Headspace, Breathwrk, etc.) uses external clock timing — inhale for 4 seconds, hold for 4, exhale for 4. Cardiac-anchored breathing inverts this: the body's own rhythm sets the pace. This is clinically significant because:

1. Each person's optimal breathing frequency varies (typically 4.5-6.5 breaths/minute for resonance)
2. Optimal frequency shifts with autonomic state, fatigue, and circadian phase
3. External timing forces the user to adapt to the app; cardiac anchoring forces the app to adapt to the user

## Implementation

Within the [[neurominute|NeuroMinute™]] architecture: the 60-second core module receives real-time cardiac oscillation data and adjusts breath pacing cues dynamically. As the user's HRV improves within a session, the system can subtly shift the breathing cadence toward the user's emergent [[resonant-breathing-frequency|resonant breathing frequency]].
