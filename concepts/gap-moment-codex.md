The structured collection of all named Gap Moment practices, each tagged with ritual metadata enabling adaptive delivery. V1.2 contains 11 practices:

1. **Non-Ergodic Blink** — irreversible choice awareness
2. **Body Time Portal** — somatic time-grounding
3. **Recursive Self-Update** — identity shift under stress
4. **Algorithmic Pause** — computational logic for overwhelm
5. **Lucid Edge** — sensory presence activation
6. **EMDR-Encoded Loop** — microtrauma reprocessing
7. **Quality Without a Name** — Alexanderian coherence tuning
8. **Outcome Pulse** — micro-OKR alignment
9. **Compassion Field** — neural re-encoding via compassion
10. **Dream Anchor** — subconscious intention setting
11. **Stairway Meta-Awareness** — five-step ascending practice

Each practice carries a standardized metadata schema: neurotarget, use case, biometric signal, affective shift, sensory modality, cultural tags, user archetypes, and developmental stage.

The Codex is the "library" layer of [[gap-moment-training]] — it organizes individual practices into a selectable, metadata-tagged system that enables adaptive delivery. The metadata enables: biometric-triggered practice selection (Apple Watch detects HRV drop and system recommends the right practice), contextual matching (pre-procedure vs. post-error), and progressive sequencing across a career arc via [[gmt-career-arc]].

Randy drove the entire codex build — providing book stacks, demanding deeper synthesis, correcting shallow readings (particularly of Christopher Alexander), and explicitly requesting ritual metadata codification. Connected to [[neurominute]] (codex practices deliverable as NeuroMinutes), [[minimum-effective-dose]] (each practice is 60 seconds), and [[kosha-architecture]] (practices map to different kosha layers).
