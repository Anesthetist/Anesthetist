Category-level positioning concept: software that senses autonomic state and delivers closed-loop audio protocols to optimize performance, with HRV-guided feedback. "Coherence per minute" as the new KPI.

## Platform Vision

The Interoceptive Flow OS unifies Pausality, VagalBeats, MPIC, and the Flow Metrics Dashboard under a single data spine. Four architectural layers:

1. **Micro-Intervention Engine** — NeuroMinute delivery with real-time adaptation
2. **Adaptive Training Tracks** — Progressive curriculum (Anterocept domains, GMT levels)
3. **Flow Metrics Dashboard** — Coherence per minute, state delta tracking, longitudinal trends
4. **Open API/SDK** — Integration points for enterprise systems, research platforms, wearables

## Strategic Significance

This concept positions Somnistics not as an app but as an operating system layer for autonomic regulation — analogous to how iOS is the OS for mobile computing, Interoceptive Flow OS is the OS for nervous system performance.
