A continuous sense-decide-act-adapt system architecture where physiological signals are captured in real-time, processed through state classification algorithms, and used to dynamically adjust intervention parameters without manual input.

## Architecture

The closed-loop cycle operates continuously during a NeuroMinute:

1. **Sense** — Capture cardiac (HRV, HR), respiratory (rate, depth), and optionally electrodermal/neural signals via wearable sensors
2. **Decide** — ML-based physiological state classification (focused, stressed, flow, dysregulated, recovering)
3. **Act** — Select and deliver the appropriate micro-intervention protocol with dynamically adjusted parameters
4. **Adapt** — Compare post-intervention biometric delta against target, modify next cycle's parameters

## Display and Shareability Layer (from Cognitive-Emotional State Interface)

The system's output is not only internal adaptation but also a shareable cognitive-emotional state representation:
- **Resilience Dial** — A color-coded summary indicator (green = optimal, orange/red = elevated stress) giving users a single glance readout
- **Micro-visualization** — 1–5 minute HRV waveform windows for trend awareness
- **Exportable snapshot cards** — Shareable "state summaries" with key metrics, a trend chart, and a one-line interpretation ("Today: achieved balanced states 60% of the time")
- **Privacy controls** — User-selected data sharing with anonymization options

This shareability layer is an important UX innovation: making the invisible physiology legible and shareable transforms individual health data into a social and professional currency.

## Patent Claims

Eight formal patent claims cover the system architecture and method, including the specific combination of multimodal sensor fusion, adaptive intervention selection, and the Five-Breath Re-Embodiment protocol.

## Differentiation from Open-Loop Systems

Unlike guided meditation apps (Calm, Headspace) that deliver fixed content regardless of physiological state, closed-loop biofeedback adapts in real-time. The intervention changes based on what the body is actually doing.

## Neural Sovereignty Architecture

Per Randy's design principle, all closed-loop processing runs on-device (edge AI first). Raw biometric data never leaves the Apple Watch or iPhone. Model personalization occurs locally. This is not a privacy feature — it is a founding ethical commitment to neural sovereignty.
