The integrated technical stack combining Apple Watch/iPhone sensors, interoceptive awareness training modules, breath protocols, and an adaptive progression engine. Randy classifies this as a "System architecture" type — the full delivery system that brings Somnistics to CRNAs.

## Components

- **Sensor layer:** Apple Watch biometrics (HR, HRV, respiratory rate, motion)
- **Training modules:** Progressive interoceptive awareness curriculum (Anterocept domains)
- **Breath protocols:** Parameterized breathing patterns (Box, Anesthetist's Breath, Rapid Reg, 4-7-8)
- **Adaptive engine:** AI-driven progression that adjusts difficulty, protocol selection, and timing based on user performance and state
- **Feedback loop:** Closed-loop biofeedback connecting sensor data to intervention delivery

## Relationship to Product

This is the system-level architecture that Pausality/PAUSE II implements. Individual concepts (NeuroMinute, Gap Moment Detection Engine, Anterocept) are components within this system.
