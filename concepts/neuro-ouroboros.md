# Neuro-Ouroboros™

A recursive 21-day breathwork and attention-training curriculum where each day's [[neurominute]] builds on prior ones, creating a self-feeding loop of deepening physiological harmony. The ouroboros (snake eating its tail) represents the closed-loop geometry: rise → hold → fall → hold sequencing that repeats with increasing complexity.

## Definition

The Neuro-Ouroboros is both a curriculum structure and a knowledge-graph metaphor. As curriculum, it delivers 21 days of progressive NeuroMinute protocols that compound neuroplastic effects. As metaphor, it represents how states, skills, and metadata loop back to refine future interventions — the system learns from itself.

## 21-Day Progressive Architecture

- **Days 1-7: Foundational Breathing** — Baseline interoceptive awareness. Simple breath protocols (coherent breathing, extended exhale). Posterior insula engagement. Corresponds to [[anterocept]] Domain 1.

- **Days 8-14: Layered Sensory Anchors** — Box breathing with multi-modal cues. Introduction of [[polyanchora]] multi-anchor attention switching. Anterior insula + TPJ recruitment. Corresponds to [[anterocept]] Domain 2.

- **Days 15-21: Cognitive/Affective Integration** — Full [[multi-phase-interoceptive-coupling]] with 4-7 concurrent interoceptive targets. Emotional valence layering (gratitude, curiosity). Non-dual awareness states. Corresponds to [[anterocept]] Domain 3.

## Recursive Design Principle

Each day's NeuroMinute:
1. Recapitulates elements from prior days (spiral review)
2. Adds one new layer of complexity (progressive overload)
3. Generates biometric data that informs the next session's parameters (closed-loop adaptation)
4. Builds toward unconscious competence — the point where regulation becomes automatic

## Neurophysiological Outcomes (Progressive)

- Progressive insula-ACC connectivity strengthening
- Increased interoceptive coherence (accuracy + awareness)
- Enhanced vagal tone and respiratory sinus arrhythmia
- Development of stable flow states with reduced cognitive effort
- Neuroplastic potentiation through infinitely repeatable layered loops
