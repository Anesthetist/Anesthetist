# NeuroHarmonics™

A three-layer frequency architecture for adaptive auditory entrainment that dynamically shifts based on real-time HRV biofeedback. Unlike static binaural beats, NeuroHarmonics responds to the user's autonomic state in real-time.

## Three-Layer Architecture

1. **Frequency Alignment Layer** — Auditory cortex + thalamus entrainment. Alpha (8-12 Hz) for relaxation, theta (4-8 Hz) for deep states, gamma (>30 Hz) for task-positive focus.

2. **Breath-Rhythm Integration Layer** — Pre-Bötzinger complex + ventral vagal complex synchronization. Audio rhythm locks to respiratory rate, creating neuro-cardio-respiratory coherence.

3. **Adaptive Soundscaping Layer** — Anterior insula + right hemisphere engagement. Dynamic environmental sounds (nature, ambient) that shift based on detected autonomic state.

## Key Innovation: Gamma for Task Focus

Distinct from typical relaxation-focused binaural beats: gamma frequencies (>30 Hz) improve problem-solving in high-pressure scenarios. This enables a "pre-surgical focus" mode — alertness enhancement, not just calming.

## Real-Time Adaptation

HRV-driven harmonic shifts: biofeedback triggers transitions between harmonic layers (e.g., deeper tones during stress recovery, brighter tones during task preparation). The system maintains coherence dynamically rather than playing static frequency tracks.
