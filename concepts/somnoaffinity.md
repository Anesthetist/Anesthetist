# SomnoAffinity™

A self-referential affirmation loop that uses the user's own recorded voice, played back during exhalation (parasympathetic phase), to create dopamine-driven neuroplastic self-identity anchoring. The mechanism goes beyond cognitive affirmation into vagal-reward coupling.

## Mechanism

- **Self-referential vocal input:** Using the user's own voice activates mPFC and PCC (medial prefrontal + posterior cingulate cortex) more robustly than external affirmations — creates identity-level neural activation
- **Breath-synchronized playback timing:** Affirmations triggered on exhalation phase leverages the parasympathetic receptive state for neuroplastic embedding — timing is critical
- **Ventral striatum reward coupling:** Dynamic feedback loop links affirmations to ventral striatum dopamine release, creating habit formation rather than cognitive-only belief change

## Why Exhalation Timing Matters

During exhalation, the vagus nerve is maximally active (parasympathetic dominance). The brain is in a receptive, low-threat state. Affirmations delivered in this window bypass the threat-detection system that normally filters self-referential positive statements as "unrealistic."
