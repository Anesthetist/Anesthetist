The CRNA Learning OS: how experts learn while performing under pressure. Randy's concept rejects the separation of learning from clinical work.

## The Four-Phase Loop

1. **Pre-case plan** (2-3 min) -- set learning intention before the case begins
2. **In-case cues** -- micro-retrieval during performance, interoceptive attention to learning moments
3. **Post-case harvest** (3-5 min) -- capture what was learned while memory is fresh
4. **Spaced retrieval** -- 10 min later, next day, next week; turning episodic memory into durable knowledge

## Four Learning Loops

1. **Knowledge** -- retrieval + spacing
2. **Discrimination** -- interleaving + contrast cases
3. **Skills** -- simulation-based deliberate practice
4. **Team/Crisis** -- CRM behaviors + cognitive aids + debriefing

## Three Non-Negotiable Artifacts

1. **Prompt Bank** -- personal question set that drives daily learning
2. **Error Log** -- personal pattern detector for mistakes and near-misses
3. **Spacing Calendar** -- so good intentions become repeatable practice

## Pedagogical Foundation

"What wires together fires together. We fail to our level of training. Train so failure results in an optimal state." (Randy, synthesis-for-novel-combinatrics)
