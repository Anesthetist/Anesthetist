How Vigil Processes Knowledge

From raw transcripts to curated vault — automatically, with human judgment where it matters

1
Assessment

Triage

Scan 861 ChatGPT files. Classify by category. Score extraction value. Prioritize the queue. Favor Randy's original thinking over AI-generated content.

Output: extraction-queue.md
2
Diagnosis

Mine

Extract Randy's voice from each transcript. Identify novel concepts, clinical observations, evidence claims. Distinguish signal from noise (15% / 85%).

Output: extraction reports
3
Planning

Validate

Check schema compliance. Search for duplicates. Decide: create, update, or flag. Quality gates enforce standards. Dublin Core + SKOS + PROV-O.

Output: validated candidates
4
Implementation

Write

Create vault notes via MCP. Wire SKOS relationships. Link evidence chains. Log every action. Never write directly — always through the server.

Output: vault notes + audit log
5
Evaluation

Review

Auto-resolve 80%+ of flagged items. Pre-draft clinical interpretations. Verify citations via PubMed. Present a 30-second dashboard to Randy.

Output: review-dashboard.md
Feedback Loops
Reflexion — self-reflection after every run
Patterns — heuristics that compound
Cross-bot — writer evaluates miner
Randy — decisions feed back to all bots

Randy reviews 5-10 items. The bots handle the rest. The queue shrinks every cycle.
