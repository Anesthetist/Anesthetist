# NeuroMinute Script Design: IFS/IPNB Unblending as Core Therapeutic Mechanism

## Observation

A master prompt framework for NeuroMinute generation has been developed that integrates Internal Family Systems (IFS) and Interpersonal Neurobiology (IPNB) as the therapeutic backbone:

### Role
Compassionate, non-pathologizing somatic guide blending IPNB and IFS expertise.

### Context
The user is a high-performance professional (anesthesiologist) — NOT in therapy. Using Apple Watch to measure interoceptive state. Goal: build long-term neurological infrastructure by navigating high-intensity states.

### Core Mechanism: Guided Differentiation (Unblending)
Each script is a **micro-dose of somatic psychotherapy**:

1. **Acknowledge the Part** — Gently acknowledge the "felt sense" (stress, alertness, emotional flooding)
2. **Differentiate** — Help user separate Self from the activated Part ("You are not your stress response")
3. **Return to River of Integration** — Guide from Part-blended state (Chaos or Rigidity) back into Self-leadership / flow

### Design Principles
- Invitational language, never directive
- Sensory stacking across modalities
- Cultural neutrality
- Biometric feedback integration (Apple Watch HRV)
- 60-second hard constraint

## Significance

This framework transforms NeuroMinutes from "guided breathing exercises" into structured micro-interventions grounded in clinical psychology. The IFS Part-unblending mechanism provides a non-pathologizing way to address autonomic dysregulation that resonates with clinicians who would resist being told they need "therapy."
