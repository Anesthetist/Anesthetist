# Agent-First SDLC 2.0: Market Observation

## The Signal

Ryan Carson (March 17, 2026):
> "The company that actually builds the agent-first code factory is going to be worth hundreds of billions of dollars. No one has cracked it yet. It can't be the model labs because then you're tied to one model. I'm hoping a company like @linear will do this. I'd happily pay thousands of dollars a month for that (+ the token cost). Basically, we need SDLC 2.0 for the agent age. (Also, the right solution can't rely on gh - we need whoever does this to completely replace it as well.)"

## The Core Insight

The winner in agent-native software development can't be a model lab (vendor lock-in) and can't be GitHub-native (legacy SDLC assumptions). What's needed is an orchestration layer that treats agents as first-class team members with persistent context, specialized roles, and coordinated workflows. Not "AI-assisted coding" but **agent-native development lifecycle**.

The hard infrastructure problems: shared state management across agents, handoff protocols between specialized roles, quality gates that keep humans in the loop without bottlenecking everything, and persistent memory that survives session boundaries.

## SRL Structural Parallel

The SRL knowledge work system is already running this architecture pattern — not for code, but for knowledge production:
- The 10-bot pipeline (transcript-triage, knowledge-miner, vault-writer, citation-resolver, compliance-gertrude, competitive-landscape, marketing-intelligence, cognitive-ethnographer, review-accelerator) is a specialized agent team with coordinated workflows
- The vault's status pipeline (draft → review → canonical) is the quality gate keeping the human (Randy) in the loop without requiring his involvement in every step
- The Chairman model is the human-in-the-loop governance layer

The gap Carson identifies for code is identical to the gap SRL has been solving for clinical knowledge: nobody has built the infrastructure layer yet. SRL is running a prototype of the agent-first knowledge factory while the code factory equivalent is still being designed.

## SRL Strategic Implication

Arrow 4 in the Five Red Arrows (Clinical LLM Moat) depends on this same orchestration infrastructure applied to clinical/regulated domains. The company that cracks "agent-first knowledge factory" for regulated/clinical contexts may be as valuable as the code factory — and the competitive field is thinner. SRL's early operational experience with this architecture pattern represents tacit knowledge that could become infrastructure IP.
