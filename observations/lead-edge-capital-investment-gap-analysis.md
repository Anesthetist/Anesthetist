# Lead Edge Capital 8 Criteria Gap Analysis

## Requirement

Need 5+ of 8 criteria satisfied for Lead Edge Capital investment.

## Criteria Assessment

| Criterion | Requirement | Current SRL Position | Action |
|-----------|------------|---------------------|--------|
| Revenue | >= $10M annually | Pre-revenue/early ARR | Build enterprise + CEU + app MRR pipeline targeting $1M ARR within 18-24 months |
| Growth | >= 25% YoY | Early-stage, potentially exponential | Design compoundable growth loops (clinician CEU to enterprise to B2C virality) |
| Profitability (Gross Margin) | >= 70% | Software + IP-based, easily 80-90% | Document margins per vertical |
| Market Size | Large addressable market | $6.8T-$10T wellness market | Quantify TAM/SAM/SOM with specificity |
| Competitive Advantage | Defensible moat | IP portfolio + clinical credibility | Formalize 7 Powers framework for investors |
| Team | Domain expertise + execution | Strong domain, building execution | Fill technical/growth gaps |
| Unit Economics | Scalable model | B2B LTV:CAC 20:1 projected | Validate with pilot data |
| Customer Retention | High NRR | Early signals from beta | Track and report cohort retention |

## Timeline Implication

Lead Edge is a growth-stage target (Series B+). This gap analysis informs what milestones to hit during Seed and Series A to position for later-stage capital.
