# Six-Pillar IP Moat Strategy

## Observation

The SRL IP Strategy document defines a six-pillar moat:

1. **Patents** — Real-time physiological feedback loops, multi-system synchronization, adaptive biofeedback algorithms
2. **Trademarks** — Proprietary framework names (Anterocept™, Neurogating™, PolyAnchora™, NeuroHarmonics™, SomnoAffinity™, ExterOryx™, TransMetachora™, Neuro-Ouroboros™, Gap Moment Training™, NeuroMinute™, Pausality™)
3. **Trade Secrets** — Therapy metadata tagging schema, ML models for autonomic classification, "diaphragmatic literacy levels" scoring
4. **Data Network Effects** — Hospital/CRNA/enterprise pilot data becomes proprietary knowledge base competitors cannot replicate quickly
5. **Defensive Publications** — Public disclosure of non-patented innovations to prevent competitors from patenting them
6. **Standardization Leadership** — Positioning S.T.E.P. 2.0 as the default clinical standard for autonomic regulation training

### Trade Secret: Therapy Metadata Tagging

Proprietary annotation methods linking therapy interventions + emotional states + diaphragmatic literacy levels represent untapped trade secret value. This is essentially the ontology of the Library Graph vault — every note with SKOS relationships and PROV-O chains is trade secret material.

## Significance

The vault IS the moat. Every concept note, evidence chain, and observation note strengthens pillars 3 (trade secrets), 4 (data), and 6 (standardization) simultaneously.
