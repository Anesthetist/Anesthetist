Most SaaS products are collections of workflows that can be rewritten as agent skills. Many will die, top ones will pivot to agent companies.

**SRL Relevance:** Pausality's breathing protocols, HRV monitoring flows, and CRNA decision support should be agent-native from day one. Don't build SaaS, build skills.
