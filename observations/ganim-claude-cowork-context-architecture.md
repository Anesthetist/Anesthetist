# Ganim — Claude Cowork Context Architecture: Sandbox + .md Files + Zapier MCP

## Key Insight
Ganim outlines the 80/20 of Claude Cowork setup: (1) sandbox folder for safety (never give full system access), (2) three .md context files — about_me, brand_voice, working_preferences — built through Claude interviewing the user, (3) Zapier MCP integration connecting 8,000 apps in 10 minutes. This represents a practical context engineering pattern for non-developer LLM power users.
