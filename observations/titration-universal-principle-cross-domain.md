## Deep Structure Identification

Both findings encode **titration/dose-response logic** across orthogonal domains:

**MVP Logic:**
- Product: Build minimum viable feature set
- Pricing: Start with minimum viable price
- Team: Hire minimum viable headcount for stage
- Documentation: Create minimum viable docs (not comprehensive)

**Effectuation Logic:**
- Career: Make small bets (not long-term plans)
- Learning: Iterate through experiments (not consumption)
- Distribution: Test small audience before scaling

All reduce to: **Find the minimum dose that produces signal, then iterate.**

## Structural Homology

Identical mathematical structure across all domains:

```
Dose (Feature Set, Price, Team Size, Bet Size) 
  → Measure (Product-Market Signal, Decision Quality, Learning Rate)
    → Adjust (Add feature, raise price, hire, increase bet)
```

This is **universal** because it respects dose-response curves in all domains.
