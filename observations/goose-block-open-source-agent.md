# Block (Dorsey) — Goose: Open-Source AI Agent with 35K Stars

## Source
Nav Toor, April 5, 2026. [https://x.com/i/bookmarks](https://x.com/i/bookmarks)

## Key Insight
Jack Dorsey's Block has released Goose, an open-source AI agent that goes beyond code suggestions — it installs, executes, edits, and tests code autonomously. At 35,000 GitHub stars, it represents a significant open-source alternative to commercial agentic coding tools (Claude Code at $200/month, GitHub Copilot at $19/month). Goose is free and community-driven.

## SRL Relevance
Competitive intelligence for SRL's agentic research lab infrastructure. As agentic AI tools commoditize (free open-source alternatives to premium services), SRL's differentiation must come from domain-specific knowledge and structured workflows (the vault, clinical ontologies, SKOS wiring) rather than from the agent framework itself. This reinforces the strategy of building on top of commodity agents with proprietary domain intelligence.
