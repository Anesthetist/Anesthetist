# Human Attention Taxonomy: Attentional Targets During Inhale vs. Exhale

## Observation

The SRL Human Attention Taxonomy maps specific attentional targets to each breath phase — not just "breathe and notice" but precisely WHAT to attend to during each phase:

### During Inhale

- **Interoceptive awareness:** Ribcage expansion, diaphragm descent, air temperature
- **Positive cognitive priming:** Affirmations ("oxygenating my mind," "energy flowing in")
- **Vagal engagement visualization:** Imagining vagus nerve activation from brainstem to heart

### During Exhale

- **Parasympathetic emphasis:** "Letting go of stress," softening muscles, releasing tension
- **Grounding focus:** Bodily relaxation sensation, weight into chair/feet
- **Temporal expansion:** Mentally slowing perception of time (connects to [[breath-as-time-engineer]])

### Attention Types with Neural Bases

| Type | Neural Substrate | SRL Application |
|------|-----------------|-----------------|
| Focused Attention | PFC, ACC, RAS | Gap moment efficacy |
| Open Monitoring | Insula, DMN, ACC | Pausality interoceptive training |
| Interoceptive Attention | Insular cortex, ACC, vagus | MAIA-2 mapping |
| Flow State | HRV-EDA-respiration coherence + reduced DMN | Biofeedback target |

### Traditional Framework Mappings

- **Yogic Pratyahara:** Sensory withdrawal → enhanced insular interoception (validates anterocept Domain 1)
- **Taoist Qigong/Tai Chi:** Parasympathetic enhancement via vagal activity + proprioceptive mapping

## Significance

This taxonomy transforms script design from intuitive to systematic. Each 60-second [[neurominute]] can now specify WHICH attention type to activate, DURING WHICH breath phase, targeting WHICH neural substrate. It's the missing link between the concept architecture and audio production.
