# Script Design: Invitational Language, Sensory Stacking, Cultural Neutrality

## Observation

The PAUSE App script development process distilled several craft principles for 60-second guided breathing scripts that directly implement [[neurominute]] Phase 1 ("acknowledge the felt sense") and Phase 2 ("invite the Self"):

### Invitational Language Rules

- **"Imagine..." not "Do..."** — co-exploration, not command
- **"Notice..." not "Feel..."** — observation, not instruction
- **Never:** "must," "fix," "get rid of," "should," "try harder"
- **Always:** "allow," "invite," "get curious about," "notice what happens when..."
- **Closing shift:** Not bare "Thank you" but affirmative: "Thank you for this moment of settling"

### Sensory Stacking Progression

Layer sensory cues gradually within each 60-second script:
1. Breath awareness (interoceptive — simplest)
2. Sound awareness (exteroceptive — ambient)
3. Tactile awareness (hand-on-belly, feet-on-floor)
4. Visual (soft gaze, light awareness)
5. Emotional valence (gratitude, curiosity)

Never introduce all channels at once. Each script adds at most one new channel.

### Cultural Neutrality Principles

- Avoid religious/cultural imagery — use universal: nature, light, breath, balance
- Offer multiple anchor points (not just breath — some cultures resist breath focus)
- Collective AND individual benefit framing (resonate across individualist/collectivist values)
- Trauma-informed: suggest, never command; respect boundaries

### Sentence Structure for Scripts

- Alternate short impactful + long descriptive (creates rhythm matching breath)
- Fronted adverbials: "Quietly... Gently... Slowly..." — guides pace without commanding
- Deliberate pauses (...) between instruction clusters — gives the nervous system time to respond

## Significance

These principles operationalize the [[awareness-before-technique]] insight at the script level. Every script word is chosen to support autonomic shift without triggering resistance, performance anxiety, or cultural exclusion.
