# Somatic Certification Curriculum Architecture

## The Five Competency Domains

### Domain 1: Attentional
Where is attention? Can you direct it? Can you sustain it under cognitive load?

**Vault concepts:** interoceptive-literacy, anterocept, relevance-realization
**Assessment:** Attention regulation subscale (MAIA-2), present-moment time tracking
**Progression:** Notice → Direct → Sustain → Sustain under load

### Domain 2: Breath
Diaphragmatic literacy, resonant frequency identification, protocol selection and execution.

**Vault concepts:** diaphragmatic-literacy, diaphragmatic-blindness, resonant-breathing-frequency, minimum-effective-dose
**Assessment:** BOLT score, breath rate accuracy, protocol execution quality
**Progression:** Perceive diaphragm → Control rate → Find personal resonant frequency → Select protocol for context → Execute under pressure

### Domain 3: Somatic Awareness
Felt-sense discrimination, body listening, interoceptive accuracy, self-compassion as clinical tool.

**Vault concepts:** interoception, interoceptive-literacy, multi-phase-interoceptive-coupling, somnoaffinity
**Assessment:** MAIA-2 full battery (especially Trusting, Attention Regulation, Body Listening subscales)
**Progression:** Notice internal signals → Discriminate signal types → Trust signals → Use signals for state classification

### Domain 4: Application
When to use which technique. Gap moment detection. State classification. Context-appropriate protocol selection.

**Vault concepts:** gap-moment-training, gap-moment-literacy, gap-moment-detection-engine, neurogating, state-transition, titration-to-effect
**Assessment:** Gap moment detection rate, protocol-context matching, state classification accuracy
**Progression:** Recognize gap moments → Classify autonomic state → Select appropriate protocol → Execute in workflow → Self-evaluate effectiveness

### Domain 5: Integration
Training frequency and sustainability. Time in present moment. Burnout trajectory tracking. Career-longitudinal development.

**Vault concepts:** neuro-ouroboros, clinician-durability, somnistics-readiness-battery, career-longitudinal-gmt
**Assessment:** Burnout scale trajectory (over time), MAIA-2 delta, HRV trend, training compliance, self-reported present-moment ratio
**Progression:** Establish baseline → Build daily practice → Track trajectory → Sustain across career stages → Mentor others

## Vault-Driven Curriculum Sequencing

The knowledge graph enables a curriculum designer bot to automatically sequence content:

1. **Read concept notes** — each has a definition, mechanism, evidence chain, and SKOS relationships (broader/narrower/related)
2. **Follow the SKOS hierarchy** — broader concepts are prerequisites for narrower ones (autonomic-regulation → vagal-tone → resonant-breathing-frequency)
3. **Map evidence depth** — concepts with more evidence links are higher-confidence teaching targets
4. **Use the five domains as parallel tracks** — each domain progresses independently but cross-links at integration points
5. **Time container mapping** — the neuro-ouroboros 21-day structure provides the proven delivery format; certification extends this across weeks/months

## Example Curriculum Sequence (8-Week Certification)

| Week | Domain 1: Attention | Domain 2: Breath | Domain 3: Somatic | Domain 4: Application | Domain 5: Integration |
|------|-------------------|-----------------|-------------------|---------------------|---------------------|
| 1 | What is attention? | Diaphragmatic literacy | MAIA-2 baseline | What is a gap moment? | Establish baseline metrics |
| 2 | Directing attention | Coherent breathing (5/5) | Body Listening | Counting your gap moments | Daily practice protocol |
| 3 | Sustaining attention | Box breathing | Trusting signals | Classifying autonomic state | Tracking HRV trend |
| 4 | Attention under load | Finding resonant frequency | Discriminating signal types | Protocol-context matching | Burnout scale check-in |
| 5 | Interoceptive attention | Extended exhale protocols | Self-compassion as tool | Pre-procedure NeuroMinute | MAIA-2 mid-point |
| 6 | Attention + breath combined | Protocol selection | Emotion as signal | Post-incident recovery | Trajectory review |
| 7 | Sustained focus under pressure | Titration to effect | Full interoceptive map | Gap moment mastery | Career-stage awareness |
| 8 | Integration assessment | Practical exam | MAIA-2 post | Scenario-based testing | Certification + maintenance plan |

## How the Knowledge Graph Serves the Curriculum

- **Concept notes** provide the teaching content (definition, mechanism, evidence)
- **Evidence notes** provide the citations and credibility for each teaching point
- **Observation notes** provide the clinical stories and examples
- **Audience notes** calibrate language register and evidence depth per learner type
- **Output notes** are the generated curriculum materials (scripts, slides, assessments)
- **SKOS relationships** determine prerequisite order
- **PROV-O chains** ensure every claim traces to a source

A curriculum designer bot reads the graph and produces sequenced content. The same vault that answered Don Katz's questions generates the week 3 lesson plan. One knowledge base, many outputs.
