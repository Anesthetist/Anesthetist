# Seven Foundation Breathing Scripts (PAUSE App)

## Observation

The PAUSE App Foundation Series defines seven progressive 60-second sessions with 7.83 Hz Schumann resonance background tone:

| Session | Technique | Key Instruction |
|---------|-----------|-----------------|
| 1 | Introduction to Breathing | Basic breath awareness, hand-on-belly tactile feedback, NO manipulation |
| 2 | Deep Breathing | Diaphragmatic, full expansion, complete exhalation |
| 3 | Box Breathing | 4-count inhale, 4-hold, 4-exhale, 4-hold |
| 4 | Resonant Breathing | 5-beat inhale, 5-beat exhale (heart-breath synchronization) |
| 5 | Pursed Lip Breathing | Normal nasal inhale, pursed-lip controlled exhale |
| 6 | Equal Breathing | 4-count balanced inhale/exhale |
| 7 | Diaphragmatic Breathing | Dual hand placement (chest + belly), chest still, belly rises |

### Design Principles

- Exactly 60 seconds per session
- 3-second pauses (...) between instructions
- Consistent opening "Welcome..." + closing "Thank you for taking this PAUSE..."
- Integration with biometric monitoring
- Session 1 is awareness-only (no technique) — validates the [[awareness-before-technique]] principle
- Progressive complexity: awareness → depth → pattern → synchronization → control → balance → precision

### Technical Detail: Schumann Resonance (7.83 Hz)

Background tone at Earth's electromagnetic resonance frequency. Research suggests entrainment effects on alpha brainwave activity — a subtle auditory anchor that supports the binaural beats layer.

## Significance

These seven scripts are the operationalized curriculum for [[anterocept]] Domain 1 (baseline interoceptive awareness). They systematically correct [[diaphragmatic-blindness]] and build the foundation for all subsequent training.
