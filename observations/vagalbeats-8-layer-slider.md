# VagalBeats 8-Layer Slider: User-Controlled Complexity from Beginner to Expert

## Observation

The VagalBeats Day 1/21 Content blueprint defines an 8-layer complexity slider that users control — adding layers as competency increases. Each 60-second loop can be practiced at any layer depth:

| Layer | Content | Engagement Level |
|-------|---------|-----------------|
| 1 | Basic breath cueing | Beginner |
| 2 | Interoceptive awareness prompts | Beginner+ |
| 3 | User's own voice affirmations ([[somnoaffinity]]) | Intermediate |
| 4 | Binaural beats ([[neuroharmonics]]) | Intermediate |
| 5 | Dual focus: interoceptive + exteroceptive | Intermediate+ |
| 6 | Stacked multi-sensory elements ([[polyanchora]]) | Advanced |
| 7 | Dynamic toggling ([[exteroryx]]) | Advanced |
| 8 | Full integration with adaptive feedback | Expert |

### Infinite Repeat Design

60-second loops deepen entrainment by the 3rd, 5th, 10th repetition through emergent pattern recognition. The same loop at Layer 1 and Layer 8 is a fundamentally different experience — the content stays the same, but the complexity of attention changes.

### Safety Principle

"Never forcing" — core differentiator vs. other apps. Users can stop at any comfortable layer. The slider goes up but never pushes. This IS [[titration-to-effect]] applied to the UI.

## Significance

The 8-layer slider unifies all the trademarked frameworks (Anterocept, PolyAnchora, ExterOryx, SomnoAffinity, NeuroHarmonics) into a single user-facing control. The user doesn't need to know the framework names — they just move the slider. The architecture does the rest.
