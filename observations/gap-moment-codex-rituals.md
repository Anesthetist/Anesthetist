# Gap Moment Codex V1.2: 11 Named Rituals with Biometric Specifications

## Observation

The Gap Moment Codex has evolved to V1.2 with 11 named rituals, each with specified neurotargets, use cases, biometric entry/exit criteria, and sensory modalities.

### Core Rituals (V1.2)

| Ritual | Mechanism | Use Case |
|--------|-----------|----------|
| The Stability Snap | Left nostril breath + containment visualization (4-2-6) | Pre-action grounding |
| The Time Horizon Arc | Medial PFC activation via future-self visualization | Urgency → longevity shift |
| The Error Reversal Loop | Posterior cingulate reset via curiosity-based breath | Post-mistake recovery |
| The Radiant Exhale | Parasympathetic reset (5-in, 7-out) + micro-smile | General calming |
| The Coherent Return | Synchronized team breathing + shared affirmation | Team re-entry |
| The Lucid Edge | Reticular activating system via sensory presence | Sharpening alertness |
| The EMDR-Encoded Loop | Bilateral tapping + amygdala-hippocampus link | Trauma processing |
| Breath-Turn Pivot | Breath direction shift at transition point | Micro-transitions |
| Visual Pull-Back | Peripheral vision expansion | Tunnel vision break |
| Somatic Label Snap | Name the felt sensation in one word | Emotional labeling |
| Pulse-Sync Tap | Tap rhythm synchronized to heartbeat | Cardiac entrainment |

### Metadata Per Ritual

Each ritual carries: neurotarget, use case, biometric entry signal, biometric exit signal, affective shift target, sensory modalities engaged. This metadata enables [[neurogating]] to select the appropriate ritual based on detected state.

### Design Influence

Cross-references Christopher Alexander's Pattern Language (architecture), Cambridge Handbook of Expertise (performance science), ergodicity economics (risk framing), and nature-soul psychology (Plotkin).

## Significance

The Codex transforms gap moment training from "do some breathing" into a structured ritual library with named protocols, each targeting specific neural circuits. This is the NeuroMinute equivalent of a pharmacopoeia — specific interventions for specific states.
