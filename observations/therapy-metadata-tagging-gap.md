# No Universal Therapy-Neuroscience Metadata Standard Exists

Randy asked about the state of combined therapy metadata and neuroscience datasets. The research confirmed a significant gap: BIDS exists for neuroimaging but does not natively support therapy session metadata. NDA/NIMH archives can house clinical data but have no universal therapy-tagging schema.

## Randy's Question

> "Is there a therapy metadata tagging combined with a neuroscience data sets in existence yet? What is the state of the science in combining?"

## Current State

- **BIDS (Brain Imaging Data Structure)** — covers neuroimaging file organization but has no schema for tagging therapeutic interventions
- **NDA/NIMH Data Archive** — can store clinical data but lacks standardized therapy session metadata
- **No universal standard exists** for cross-referencing therapy modalities with their neurophysiological targets and outcomes

## Strategic Implication

This gap represents a foundational infrastructure opportunity for SRL's [[neurotagging]] concept. If SRL establishes a metadata standard for tagging therapeutic micro-interventions (NeuroMinutes) with their neurophysiological targets and measured outcomes, it could become the de facto schema for the emerging field of technology-augmented interoceptive training.
