# Cheng Lou — CSS-Free Text Measurement: The Next Foundation of UI Engineering

## Source
Cheng Lou (@_chenglou), March 27, 2026. [https://x.com/_chenglou/status/2037713766205608234](https://x.com/_chenglou/status/2037713766205608234)

Creator of ReasonML, ReScript, and former React core team member (also worked on Messenger and Midjourney). Post received 963 replies, 7.5K reposts, 48K likes, 13.6M views — unusually high engagement for a deep technical post.

## Key Insight
Cheng Lou released a fast, accurate, and comprehensive **userland text measurement algorithm in pure TypeScript**, enabling complete web page layout without CSS, bypassing DOM measurements and browser reflow entirely. He frames this as "one of the more important foundational pieces of UI engineering" for the foreseeable years — not necessarily in implementation but certainly in concept. This suggests a future where interfaces can be composed, measured, and rendered without dependence on browser rendering pipelines, enabling more predictable, performant, and platform-agnostic UI delivery.

## SRL Relevance
For SRL's product development (Anterocept, Pausality app, any wearable-adjacent interface), this represents a significant shift in how UI rendering could work in environments where CSS/DOM access is limited or costly — including native apps, embedded systems, or AR/VR interfaces. The conceptual implication is more important than the implementation: interfaces may increasingly be computed independently of display technology, which aligns with SRL's vision for interoceptive interfaces that must work across wearables, mobile, and eventually ambient computing platforms. Additionally, the extraordinary viral reach (13.6M views) signals that developer tooling of this kind is resonant with the engineering community SRL may need to recruit from.
