# Varun Malhotra: Mark Leonard's AI Agent Displacement Playbook, the Veeva Case Study

**Source:** [@varunv_malhotra](https://x.com/varunv_malhotra/status/2035344007706841204)
**Date:** Mar 21, 2026
**Domain:** Startup Strategy and Fundraising

## Observation

Varun Malhotra surfaces a rare public statement from Constellation Software CEO Mark Leonard, in which Leonard maps the precise playbook AI agent companies will run to displace vertical SaaS businesses. His named case study is Veeva (life sciences CRM and data platform). The pattern: AI-native entrants target the workflow layer first, build domain-specific data advantages through usage, then migrate customers by offering superior automation at lower cost. Leonard was wargaming this scenario at all-time highs, before any competitive pressure materialized. His point: the companies that survive are the ones modeling the attack before it arrives.

## SRL Implication

Pausality operates in a clinically-adjacent domain with deep workflow integration in perioperative care, which places it squarely in the same attack surface category as Veeva. The question is not whether an AI-native competitor will attempt this displacement, but when and from which direction. Running Leonard's framework as a structured competitive analysis on Pausality's own product is a board-level conversation and an investor relations asset. A 1-page competitive positioning brief that demonstrates this level of self-awareness would differentiate Pausality in any fundraising context.

## Action

Run the Mark Leonard wargame on Pausality: map current workflow integrations, identify which data advantages are defensible, locate the exposure points, and produce a 1-page competitive positioning brief for board and investor use.
