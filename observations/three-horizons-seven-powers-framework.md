# Three Horizons x Seven Powers: Strategic Planning Framework for SRL

## Framework

Cross-references Hamilton Helmer's Seven Powers with McKinsey's Three Time Horizons to extract strategic and developmental insight at every timescale.

## Horizon 1: Operational Present (EBITDA Mindset)

"How does today's execution express Somnistics' current moat-in-motion?"

- Scale Economies: Real-time data from iPhone/Apple Watch feeding adaptive algorithms
- Network Effects: Collective HRV/CO2 tolerance benchmarks refining coaching precision
- Counter-Positioning: Clinician-founded precision-breathwork vs generic mindfulness apps
- Switching Costs: Personalized biometric baselines + adaptive interventions tuned to physiology
- Branding: "Teach the world how to breathe" as Florence Nightingale-level care philosophy
- Cornered Resource: AANA partnership + live CRNA datasets
- Process Power: Continuous feedback loop between CEU curriculum and product design

## Horizon 2: Growth and Experimentation (2-5 Years)

"How do we design repeatable pathways that compound learning into durable advantage?"

- Counter-Positioning: Gap Moment Training as new category before others recognize its value
- Switching Costs: Apple HealthKit + CEU certification loop integration
- Cornered Resource: MIRA-36 meta-intelligence index, patent filings
- Process Power: AI-guided script generation system refining with user physiology data

## Horizon 3: Visionary Future (Blue Sky)

"What emergent capabilities could make SRL a civilization-scale nervous system educator?"

- Scale Economies: Breath and biofeedback literacy as universal as reading; global NeuroMinutes standard
- Network Effects: Real-time collective coherence metrics for organizations and families
- Counter-Positioning: From reactive mindfulness to proactive physiological literacy
- Switching Costs: API standard for biofeedback in all wearables
- Cornered Resource: The Somnistics Knowledge Graph linking SNOMED, HRV, interoceptive markers
- Process Power: Adaptive learning AI trained on global interoceptive diversity
