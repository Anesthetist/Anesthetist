# Content Template Forge SOP

## Core Principle

"Process sets you free." Every effective asset gets deconstructed into a reusable template within 24 hours using the Template Forge SOP:

1. **Select the win** — asset hits ≥1 success metric
2. **Deconstruct** — identify hook → promise → proof → path
3. **Abstract** — replace specifics with variables: `{Audience}`, `{Pain}`, `{Mechanism}`, `{Outcome}`, `{CTA}`
4. **Package** — name as `T-[type]-[use]-vX`, add 3-bullet usage note
5. **Test & store** — use it same day; if it works, bump version

## The Nine Templates

### 1. Daily Content (≤300 words)
Hook (≤20 words) → Credibility (1 line) → 3 Steps → Proof → CTA

### 2. NeuroMinute Script (60s, audio-ready)
- 00:00–00:05 | Set: "Eyes soft. Jaw unclench. Exhale fully." *(haptic pulse)*
- 00:05–00:15 | Anchor: feet + chair, name sensation
- 00:15–00:30 | Breath pattern: Inhale {4}, hold {0}, exhale {6}, repeat ×3
- 00:30–00:45 | Interoceptive label: notice heart rate, no fixing
- 00:45–00:55 | Expansion: widen peripheral vision
- 00:55–01:00 | Commit: "Choose your next right action. Go."
- **Metadata tags**: `{neurotarget}`, `{context}`, `{expected shift}`, `{contraindications}`

### 3. Landing Page Wireframe
Hero → Credibility bar → How it works (3 cards) → Proof → Science → Plans → Final CTA

### 4. Method × Symptom Post (SEO/ads)
Title: "{Method} for {Symptom}: the 60-second protocol" → Problem → Mechanism → Protocol → Mistakes → Measure → CTA

### 5. Email Gap Moment Sequence (3 emails)
E1 Promise → E2 Proof → E3 Path

### 6. Diagnostic Scorecard (0–10)
Problem? + Promise? + Mechanism? + Proof? + CTA? → Ship if ≥8

### 7. Ad Creative (15–30s)
Open (2s) → Explain (8s) → Show (12s) → Call (3s)

### 8. Ops Metrics
Content KPIs: scroll ≥60%, CTR ≥2.5%, lead magnet CR ≥20%
NeuroMinute KPIs: completion ≥80%, calm +2/5pt, RR ↓≥2 bpm, HRV↑ session-over-session

### 9. Storage & Versioning
Templates: `T-[type]-[use]-vX` | Ads: `A-[channel]-[campaign]-vX` | NeuroMinutes: `NM-[context]-vX`
Folders: `/Templates`, `/Live Assets`, `/Graveyard`, `/Proof`
