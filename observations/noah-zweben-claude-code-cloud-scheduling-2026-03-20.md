# Noah Zweben: Claude Code Cloud Scheduling Now First-Class Platform Feature

**Source:** [@noahzweben](https://x.com/noahzweben/status/2035122989533163971)
**Date:** Mar 20, 2026
**Domain:** Claude and Context Engineering / Autonomous Research Infrastructure

## Observation

Noah Zweben announced that Claude Code now supports recurring cloud-based scheduled tasks natively: set a repo, a schedule, and a prompt, and Claude runs it via Anthropic's cloud infrastructure without requiring a local machine to stay running. This is now an officially supported platform feature, not a workaround.

## SRL Implication

This is the infrastructure layer that SRL's weekly intelligence report (the one you are reading) runs on. The strategic implication has shifted: since this is now a supported platform feature, the competitive edge is no longer in knowing the capability exists. It is in the depth, reliability, and sophistication of the workflows built on top of it. SRL should be increasing the complexity and business value of its scheduled task library, not just the breadth. The moat is in the workflows, not the access.

## Action

Audit current SRL scheduled tasks. Identify the 3 highest-leverage additions. Prioritize reliability and output quality on existing tasks before adding new ones.
