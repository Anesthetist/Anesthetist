# Editor Bot — Learning Log

## Session Log

### 2026-04-11 — Bot Creation

- **Context:** Created as the 11th SRL bot to serve as quality gate for all generated output
- **Design decisions:**
  - Positioned as Evaluation phase in the collective ADPIE pipeline (after vault-writer implements, editor evaluates)
  - Voice Standard derived from Randy's actual communication patterns across vault outputs, emails, and proposals
  - Gertrude integration built into the protocol for public-facing content
  - Multi-pass protocol for long-form content (structure → evidence → voice → compliance → polish)
- **Patterns to watch for:**
  - AI-generated content tends to over-explain and repeat. The #1 editorial fix will likely be cutting filler
  - ChatGPT-origin drafts tend toward prescriptive language ("you should...") that conflicts with SRL's descriptive philosophy
  - Investor communications need the most regulatory latitude but the highest factual accuracy
  - NeuroMinute scripts need the tightest timing discipline (60 seconds read-aloud)
