# Cognitive Ethnographer Bot — Run Protocol

## Pre-Run Checklist

1. Read `_bots/cognitive-ethnographer/soul.md` — internalize the persona and theoretical grounding
2. Read `_bots/cognitive-ethnographer/patterns.md` — load accumulated cognitive patterns from prior runs
3. Read `_bots/cognitive-ethnographer/learning-log.md` — know what was learned last time
4. Read `outputs/articles/cognitive-development-arc-randy-graybeal-2023-2026.md` — the baseline developmental analysis
5. Read the 6 phase observations in `observations/phase-*` — know where Randy is developmentally
6. Load the target transcript(s) or vault content to analyze

## Execution Steps

### Step 1: Frame the Observation Window

Define what you're looking at:
- A single transcript? A cluster of transcripts by theme? A comparison across time periods?
- What cognitive phenomenon are you investigating? (heuristic use, domain transfer, expertise staging, tacit externalization)

### Step 2: Code the Data

Apply ethnographic coding to the source material:

**First-pass codes (descriptive):**
- `[QUESTION-TYPE]` — information-seeking / framework-testing / system-designing / hypothesis-generating
- `[CORRECTION]` — where Randy redirects the AI (corrections = expertise markers)
- `[ANALOGY]` — cross-domain transfer attempts
- `[COINED-TERM]` — moments of naming (Nonaka externalization)
- `[BODY-REFERENCE]` — when Randy grounds reasoning in somatic experience
- `[META-COGNITIVE]` — Randy observing his own thinking process
- `[DECISION-PATTERN]` — recognition-primed vs. analytical reasoning (Klein)
- `[TOOL-USE]` — how Randy extends cognition through AI, vault, wearables

**Second-pass codes (interpretive):**
- `[DREYFUS-STAGE]` — classify the cognitive operation by expertise level
- `[SECI-MODE]` — which Nonaka knowledge conversion is occurring
- `[SCHON-TYPE]` — knowing-in-action / reflection-in-action / reflection-on-action
- `[TRANSFER-MECHANISM]` — how knowledge moves between domains

### Step 3: Identify Patterns

Look for recurring cognitive structures:
- Does Randy consistently use the same anchor point when evaluating new ideas?
- Does his question complexity increase over time within a session? Across sessions?
- When does he switch from analytical to intuitive reasoning?
- What triggers a domain transfer (clinical → entrepreneurial → contemplative)?
- Where does distributed cognition appear (offloading to AI, vault, or tools)?

### Step 4: Ground in Theory

For each pattern identified:
1. Which established framework explains it? (Schön, Nonaka, Dreyfus, Klein, Hutchins, Ericsson)
2. Does it extend the framework or merely exemplify it?
3. If extending: what specifically is added? (Be precise — "extends" must be defensible)
4. If exemplifying: what makes this instance interesting? (unusual context, unusual data type, unusual scale)

### Step 5: Write Field Note

Produce an ethnographic field note per the format in soul.md. Write to `outputs/ethnography/{slug}.md`.

### Step 6: Cross-Reference with Vault

- Does this cognitive pattern explain why a vault concept exists?
- Does it connect to the cognitive-development-arc?
- Should it be linked to existing concepts via SKOS?
- Does it inform product design (e.g., how the certification curriculum should be structured based on how expertise actually develops)?

### Step 7: Run Retrospective

After completing the analysis:
1. What cognitive patterns were most surprising?
2. What could not be determined from the data?
3. What additional data would be needed?
4. What alternative interpretations exist?
5. Append to `_bots/cognitive-ethnographer/learning-log.md`

## Processing Guidelines

### Analyzing Single Transcripts
Focus on micro-level cognitive operations: question types, correction patterns, reasoning shifts within a single conversation.

### Analyzing Transcript Clusters
Focus on meso-level patterns: how Randy's approach to a topic evolves across multiple conversations on the same theme.

### Analyzing the Full Corpus
Focus on macro-level developmental trajectories: Dreyfus stage shifts, SECI mode changes, the cognitive breathing pattern.

### Working with Existing Vault Content
The vault itself is a cognitive artifact. How Randy organized knowledge (what's a concept vs. observation, what's connected to what) reveals cognitive structure. Analyze the graph topology, not just the content.
