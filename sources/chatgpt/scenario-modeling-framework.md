## Scenario Modeling One-Pager

**Purpose:** Turn uncertainty into **decision-ready strategy** (clarity, necessity, productivity, moderation, relationships, courage, compounding).

### 1) Foundation: Clarity Lock (before building)
- **Decision statement:** We will decide ___ by ___ based on ___.
- **Horizon + deadline:** ___ months; decision date ___.
- **Primary KPI + constraint KPI:** ___ and ___ (e.g., runway, covenant headroom).
- **A-Game stakeholder:** who must trust this; who will challenge it.
- **Outputs:** 1-slide exec readout + assumptions appendix (or dashboard).

### 2) Execution: PQO (80/20) + Complexity Budget
- **Driver shortlist:** score variables on Impact, Uncertainty, Stakeholder focus, Controllability, Data quality.
- **Keep 5–12 primary drivers:** everything else becomes parameters or backlog.
- **Thin-slice build:** Inputs → core logic → 1 chart. Iterate.
- **Complexity budget:** no hard-coded constants in formulas; use helper cells; every output ties to an Assumption ID.

### 3) Scenario Set: Risk + Recovery + Opportunity
- **Required scenarios:** Base, Downside, Upside, Buffer (capital preservation).
- **Recovery paths:** what actions restore KPI if downside hits.
- **Opportunity captures:** what we do if upside conditions appear.
- **Triggers:** If KPI crosses ___ by date ___ → action ___ within ___ days.

### 4) Validate & Audit: Credibility is a feature
- **Assumptions register:** definition, unit/time base, source, owner, confidence, last validated.
- **Ground-truth reviews:** 30 min with department owners to validate the top assumptions.
- **3-pass audit:** (1) extreme values, (2) units/time base, (3) reconcile to known totals.
- **Sensitivity:** tornado + break-even points for key decisions.

### 5) Deliver & Influence: Tell the truth, then give levers
- **Exec readout (1 slide):** probability bands, key drivers, triggers, recommended actions.
- **Courage rule:** state uncomfortable results plainly, paired with thresholds and options.
- **Decision thresholds:** “If X then Y” so leadership can act without re-litigating the model.

### 6) Iterate & Compound: Technical compound interest
- **10-min AAR:** what assumption mattered most; where we over/under-modeled; what broke; one upgrade.
- **30 min/day skills:** (1) rebuild a pattern, (2) learn one tool, (3) audit drill.
- **Versioning:** one source of truth; change log; freeze inputs for board versions.

### 60-Second Transition (between deep-work blocks)
- **0–20s:** 3 cycles: inhale (2s) + top-up (1s) + long exhale (5–7s).
- **20–40s:** drop shoulders, unclench jaw, relax hands; scan for tension and release.
- **40–60s:** set intention: “Next block, I will produce ___ and validate it by ___.”
- **Rule:** run the transition before any audit pass or stakeholder review.

**Tip:** Keep every assumption in one visible table; never bury constants in formulas.
