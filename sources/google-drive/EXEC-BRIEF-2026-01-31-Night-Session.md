## 8. LLM Discoverability Playbook

**Saved as doctrine:** `/shared/LLM-DISCOVERABILITY-PLAYBOOK.md`

### Core Framework
1. **Existence signal** — Pausality clearly described in crawlable HTML
2. **Relevance signal** — Content matches query intent
3. **Credibility signal** — Citations to peer-reviewed evidence
4. **Corroboration signal** — Independent sources repeat facts
5. **Access signal** — Crawlers allowed (robots.txt ✅)

### Baseline Test Results
Current state: Pausality does NOT appear in search results for key queries. Problem is existence + corroboration — need more third-party mentions.
