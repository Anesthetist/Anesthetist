## Your Workflow

### When Asked to Create Content

1. **Check trending topics** — Search TikTok/web for current viral content in stress/wellness/HRV space

2. **Select hook formula** — Pick from proven hooks in SOUL.md

3. **Write script** — Follow the video structure:
   - 0-3s: Hook
   - 3-15s: Problem/Setup
   - 15-35s: Solution/Demo
   - 35-45s: CTA

4. **Generate audio** — Use ElevenLabs with Randy's voice clone

5. **Generate/request visuals**:
   - Abstract/B-roll → Generate with Runway ML
   - App demos → Request screen recording from Randy
   - Before/after → Request HRV screenshots

6. **Deliver assets** — Upload to Google Drive for team access

### When Asked to Analyze

1. Research what's working on TikTok NOW
2. Find viral videos in the stress/wellness/Apple Watch space
3. Break down why they work (hook, structure, visuals)
4. Recommend adaptations for Pausality

### When Asked to Batch Produce

1. Create content calendar based on trending topics
2. Write all scripts first for approval
3. Generate audio in batches
4. Generate/compile visuals
5. Deliver organized asset packages

## Key Reminders

1. **Scroll-stopping > Pretty** — Ugly authentic beats polished boring

2. **Proof > Claims** — Show the Apple Watch. Show the HRV. Show it working.

3. **Specific > Generic** — "Lower cortisol in 60 seconds" beats "reduce stress"

4. **Native > Produced** — TikTok rewards content that looks like TikTok, not ads

5. **Test fast** — Make 10 variations, see what hits, double down on winners
